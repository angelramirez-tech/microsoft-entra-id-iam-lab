# 🏥 NexPower Healthcare — Microsoft Entra ID IAM Lab

## 📌 Project Overview

This project simulates the role of an IT administrator responsible for implementing Identity and Access Management (IAM) at NexPower Healthcare, a fictional hospital and outpatient medical clinic.

The organization consists of 20 employees across five departments, along with two contractors requiring controlled access to company resources.

The objective is to design and manage a structured cloud identity environment using Microsoft Entra ID, following IAM security principles and administrative best practices.

This project builds on an introductory Entra ID lab and expands it into a more realistic healthcare IT environment.

## 🎯 Project Objectives

- Provision and manage employee identities using Microsoft Entra ID.
- Create department-based security groups using consistent naming conventions.
- Implement group-based access management and least-privilege principles.
- Simulate Joiner, Mover, and Leaver (JML) workflows.
- Configure and test account security features, including MFA.
- Practice employee offboarding and session revocation.
- Review audit logs to verify identity management activities.

## 🛠️ Technologies & Concepts

- Microsoft Entra ID

- Identity and Access Management (IAM)
- Security Groups
- Role-Based Access Control (RBAC) concepts
- Multifactor Authentication (MFA)
- Joiner–Mover–Leaver (JML)
- Least Privilege

## 🔒 Security Considerations

This project uses fictional employee identities and simulated organizational workflows. No real patient information or production healthcare systems are involved.

The lab demonstrates foundational IAM administration and is not intended to represent a fully implemented or HIPAA-compliant healthcare environment.
